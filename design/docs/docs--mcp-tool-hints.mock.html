/docs/mcp/tools — each tool’s title and its behaviour hint (a delta)

A delta on design/docs/docs.mock.html: only the tool ROW and one line at the top of the page change. Since MOTIR-6974 every row of the published catalogue carries a human title and MCP annotations; the page shows neither. This draws the title beside the name, one hint chip per row in the area’s existing chip recipe, the row a hint-less Motir version produces, and the narrow width. Everything else on the page — the rail, the group headings, the argument tables, the unreachable state — is the base asset’s and is not redrawn.

This list is fetched from Motir when the page is requested, so it is whatever the server ships right now. Each tool shows the arguments it takes … (the shipped paragraph, unchanged)

Each tool says what it does to your data: Reads changes nothing, Writes only adds, and Destructive may change or remove what is already there. Claude reads these hints, and asks before using a tool that is not read-only unless you have allowed it.

Argument tables render one level: a nested object or a list shows its type, and the handshake carries the shape inside it.
