{{slot:catalogue-summary}}

此列表在请求本页时从 Motir 获取，因此就是服务器当前实际发布的内容。每个工具都会显示它接收的参数——名称、类型以及哪些是必填——这些信息读取自同一个注册表，该注册表也负责回答对上方所示端点发起的 `tools/list` 握手；握手仍然是权威来源，并带有每个工具的完整描述。某个令牌可以调用其中哪些工具，取决于它所携带的授权，因此你的客户端显示的列表已经按你的权限范围过滤。

{{slot:hint-legend}}

参数表只展示一层：嵌套对象或列表会显示其类型，其内部结构由握手返回。
