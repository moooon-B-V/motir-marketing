{{slot:catalogue-summary}}

Deze lijst wordt bij Motir opgehaald op het moment dat de pagina wordt opgevraagd, dus het is wat de server nu levert. Elke tool toont de argumenten die hij accepteert — hun namen, hun typen en welke verplicht zijn — gelezen uit hetzelfde register dat een `tools/list`-handshake beantwoordt tegen het endpoint hierboven. Dat blijft het gezaghebbende oppervlak en bevat de volledige beschrijving van elke tool. Welke tools een bepaald token mag aanroepen, hangt af van de rechten die het draagt, dus de lijst die je client toont is al op jou afgestemd.

{{slot:hint-legend}}

Argumententabellen tonen één niveau: een genest object of een lijst toont zijn type, en de handshake bevat de vorm daarbinnen.

{{slot:catalogue}}

[MCP-server](/docs/mcp) behandelt hoe je een agent aan het endpoint koppelt en welk token daarvoor nodig is.
