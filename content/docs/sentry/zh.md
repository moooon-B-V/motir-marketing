把 Sentry 连接到 Motir 项目后，你的服务已经在上报的错误会作为缺陷工作项出现在该项目的面板上——像其他任何工作一样被规划、分配并推进到完成。修复缺陷即可闭环：Motir 会替你在 Sentry 中将该错误标记为已解决。

## 它做什么 {#what-it-does}

- **每个新错误变成一个缺陷。** Motir 会按计划检查你所选的 Sentry 项目。它此前未见过的错误，会作为 `bug` 工作项提交到项目为缺陷指定的位置，附带该错误的出错位置、级别以及返回 Sentry 的链接。
- **重复出现会更新同一个缺陷。** 错误再次发生时，会更新它已有的缺陷——不会重复提交。
- **在 Motir 中完成，就是在 Sentry 中解决。** 缺陷进入完成状态时，Motir 会在 Sentry 中解决它对应的错误。
- **Sentry 的负责人会跟随错误。** 如果某个错误在 Sentry 中被分配给了某人，而此人是 Motir 工作区的成员（按邮箱匹配），缺陷就会分配给此人。

这两个方向都可以按受监控的项目分别关闭——见[设置](#settings)。

## 开始之前 {#before-you-start}

- 在 Motir 中，你需要有管理该项目集成的权限。没有该权限时，“监控”页面会告诉你该找谁。
- 在 Sentry 中，你需要有权在你的组织中安装集成——通常是所有者或管理者。

## 连接 Sentry {#connect-sentry}

1. 在 Motir 中，打开项目设置并选择 _监控_。
2. 选择 _连接 Sentry_。你会被带到 Sentry。
3. 在 Sentry 中选择你的组织并批准安装。Sentry 会把你送回 Motir，Motir 会显示 _Sentry 已连接。_
4. 选择 _选择 Sentry 项目_，选中其错误应当进入此面板的项目，然后确认。在你完成这一步之前，不会有任何内容进入。

你可以从一个 Motir 项目监控多个 Sentry 项目，之后还可以通过 _添加受监控的项目_ 添加更多。

## 设置 {#settings}

每个受监控的项目都有各自的设置：

- **最低级别**——只提交此级别及以上的错误。默认值是 _所有级别_。选择更低的级别时，还会检查自该项目开始被监控以来更早的错误。
- **缺陷完成时，在 Sentry 中将问题标记为已解决**——默认开启。关闭后，缺陷完成时，错误会保持它在 Sentry 中的原状。
- **从 Sentry 获取负责人**——默认开启。关闭后，将忽略在 Sentry 中进行的分配。

## 它请求的权限 {#permissions-it-asks-for}

Motir 只向 Sentry 请求这些功能所需的最小权限集合，不会更宽：

| Sentry 权限范围 | Motir 用它来做什么                                                                                                       |
| --------------- | ------------------------------------------------------------------------------------------------------------------------ |
| `org:read`      | 读取连接的是哪个组织，列出它的项目以便你选择要监控哪些，并检查连接是否仍然有效。                                         |
| `project:read`  | 读取你选择监控的项目。                                                                                                   |
| `event:read`    | 读取受监控项目中的新错误——它们的标题、级别、出错位置、发生次数、最新的堆栈帧以及分配给谁——以便每个错误都能作为缺陷到达。 |
| `event:write`   | 在缺陷完成时，把对应的错误在 Sentry 中标记为已解决。不会写入其他任何内容。                                               |

Sentry 授予的访问凭据以加密方式存储，不会向任何人（包括你）展示。

## 当连接显示为已降级时 {#when-the-connection-shows-degraded}

_已降级_ 表示 Motir 不再能读取你所在组织的错误，在修复之前不会有新内容到达面板。在 _Sentry 返回：_ 旁边，页面会用 Sentry 自己的原话显示原因。

- 先选择 _重新检查_——Sentry 一侧的临时故障会自行消除。
- 如果仍处于降级状态，选择 _重新连接_。如果 Sentry 提示该集成已经安装，请先在你的 Sentry 组织的集成设置中卸载 Motir，然后再次选择 _重新连接_。你的受监控项目、它们的设置以及已经提交的缺陷都会保留。

## 断开连接 {#disconnect}

要停止监控某个 Sentry 项目，请使用其所在行上的 _停止监控_。移除最后一个受监控的项目就是 _断开 Sentry_：这也会移除 Motir 存储的、对你所在组织的访问凭据，之后若想再次监控，需要重新通过 Sentry 连接。

已经提交的缺陷会作为普通工作项继续留在面板上。断开连接不会更改 Sentry 中的任何内容。如果也想在 Sentry 一侧撤销访问权限，请在你的 Sentry 组织的集成设置中卸载 Motir。
