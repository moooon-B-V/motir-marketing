把 Sentry 連線到 Motir 專案後，你的服務已經在回報的錯誤事件會作為錯誤工作項目出現在該專案的看板上——像其他任何工作一樣被規劃、分配並推進到完成。修復錯誤即可形成閉環：Motir 會替你在 Sentry 中將該錯誤事件標記為已解決。

## 它做什麼 {#what-it-does}

- **每個新錯誤事件變成一個錯誤。** Motir 會按計畫檢查你所選的 Sentry 專案。它此前未見過的錯誤事件，會作為 `bug` 工作項目提交到專案為錯誤指定的位置，附帶該錯誤事件的出錯位置、等級以及連回 Sentry 的連結。
- **重複出現會更新同一個錯誤。** 錯誤事件再次發生時，會更新它已有的錯誤——不會重複提交。
- **在 Motir 中完成，就是在 Sentry 中解決。** 錯誤進入完成狀態時，Motir 會在 Sentry 中解決它對應的錯誤事件。
- **Sentry 的負責人會跟隨錯誤事件。** 如果某個錯誤事件在 Sentry 中被分配給了某人，而此人是 Motir 工作區的成員（依電子郵件比對），錯誤就會分配給此人。

這兩個方向都可以按受監控的專案分別關閉——見[設定](#settings)。

## 開始之前 {#before-you-start}

- 在 Motir 中，你需要有管理該專案整合的權限。沒有該權限時，「監控」頁面會告訴你該找誰。
- 在 Sentry 中，你需要有權在你的組織中安裝整合——通常是擁有者或管理者。

## 連線 Sentry {#connect-sentry}

1. 在 Motir 中，開啟專案設定並選擇 _監控_。
2. 選擇 _連線 Sentry_。你會被帶到 Sentry。
3. 在 Sentry 中選擇你的組織並核准安裝。Sentry 會把你送回 Motir，Motir 會顯示 _Sentry 已連線。_
4. 選擇 _選擇 Sentry 專案_，選中其錯誤事件應當進入此看板的專案，然後確認。在你完成這一步之前，不會有任何內容進入。

你可以從一個 Motir 專案監控多個 Sentry 專案，之後還可以透過 _新增受監控的專案_ 新增更多。

## 設定 {#settings}

每個受監控的專案都有各自的設定：

- **最低等級**——只提交此等級及以上的錯誤事件。預設值是 _所有等級_。選擇更低的等級時，還會檢查自該專案開始被監控以來更早的錯誤事件。
- **錯誤完成時，在 Sentry 中將錯誤事件標記為已解決**——預設開啟。關閉後，錯誤完成時，錯誤事件會保持它在 Sentry 中的原狀。
- **從 Sentry 取得負責人**——預設開啟。關閉後，將忽略在 Sentry 中進行的分配。

## 它請求的權限 {#permissions-it-asks-for}

Motir 只向 Sentry 請求這些功能所需的最小權限集合，不會更寬：

| Sentry 權限範圍 | Motir 用它來做什麼                                                                                                                 |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `org:read`      | 讀取連線的是哪個組織，列出它的專案以便你選擇要監控哪些，並檢查連線是否仍然有效。                                                   |
| `project:read`  | 讀取你選擇監控的專案。                                                                                                             |
| `event:read`    | 讀取受監控專案中的新錯誤事件——它們的標題、等級、出錯位置、發生次數、最新的堆疊框架以及分配給誰——以便每個錯誤事件都能作為錯誤到達。 |
| `event:write`   | 在錯誤完成時，把對應的錯誤事件在 Sentry 中標記為已解決。不會寫入其他任何內容。                                                     |

Sentry 授予的存取憑證以加密方式儲存，不會向任何人（包括你）展示。

## 當連線顯示為已降級時 {#when-the-connection-shows-degraded}

_已降級_ 表示 Motir 不再能讀取你所在組織的錯誤事件，在修復之前不會有新內容到達看板。在 _Sentry 表示：_ 旁邊，頁面會用 Sentry 自己的原話顯示原因。

- 先選擇 _重新檢查_——Sentry 一側的臨時故障會自行消除。
- 如果仍處於降級狀態，選擇 _重新連線_。如果 Sentry 提示該整合已經安裝，請先在你的 Sentry 組織的整合設定中解除安裝 Motir，然後再次選擇 _重新連線_。你的受監控專案、它們的設定以及已經提交的錯誤都會保留。

## 斷開連線 {#disconnect}

要停止監控某個 Sentry 專案，請使用其所在行上的 _停止監控_。移除最後一個受監控的專案就是 _斷開 Sentry_：這也會移除 Motir 儲存的、對你所在組織的存取憑證，之後若想再次監控，需要重新透過 Sentry 連線。

已經提交的錯誤會作為普通工作項目繼續留在看板上。斷開連線不會更改 Sentry 中的任何內容。如果也想在 Sentry 一側撤銷存取權限，請在你的 Sentry 組織的整合設定中解除安裝 Motir。
