公開プロジェクトには、お客様が選んだアドレスでアクセスできます。ワークスペースごとに専用のアドレスを 1 つ取得できます。さらに、すでにお持ちのドメインでプロジェクトを表示することもできます。

## Motir アドレス {#your-motir-address}

ワークスペースは、サブドメインを 1 つ取得します。そのワークスペースのすべての公開プロジェクトは、このサブドメインの配下に表示されます。たとえば `acme` を取得すると、`acme.motir.site/ROADMAP` でアクセスできるようになります。これは、キーが `ROADMAP` のプロジェクトの場合です。取得できるのはワークスペースのオーナーまたは管理者で、プロジェクト設定の _公開アドレス_ から行います。

ラベルには、小文字の英字、数字、ハイフンを使用でき、長さは 3 文字から 63 文字です。Motir 自身のホストに使う名前や、それと誤認されうる名前はあらかじめ確保されています。

名前の変更回数には上限があり、残りの回数は画面に表示されます。**古いアドレスはその後も引き続き機能し、解放されることはありません。** 新しいアドレスへ恒久的にリダイレクトされ、後からご自身を含めて誰も取得できなくなります。これは意図した仕様です。すでに誰かに共有されたリンクが、ある日突然、お客様が選んでいない場所につながってはならないからです。

## 独自ドメインの接続 {#connecting-your-own-domain}

所有しているドメインの接続は有料プランでご利用いただけます。詳しくは[プランのページ](/)をご覧ください。ワークスペースのサブドメインはすべてのプランに含まれ、どちらの場合も引き続き利用できます。

接続したドメインが配信するプロジェクトは _1 つ_ だけで、そのドメインのルートに表示されます。`roadmap.acme.com/` がそのプロジェクトのページ、`roadmap.acme.com/changelog` が変更履歴のページです。ライブのボード、作業項目、ロードマップは Motir アプリ内にあり、そこからのリンクで開きます。

レジストラで作成するレコードは 2 種類です。**最初にドメインを追加してください。** 追加はプロジェクト設定の _公開アドレス_ で行います。すると、そのドメインに必要なレコードがすべて、正確な値とコピーボタンとともに画面に一覧表示されます。以下に示すのは、あらかじめ想定しておくべきレコードの形です。レジストラでそれらを作成できるかを確認する目安として読み、実際の値は画面から取得してください。

### 1 · ドメインを Motir に向ける {#point-the-domain-at-us}

`roadmap.acme.com` のような**サブドメイン**には、`CNAME` を 1 つ作成します。

| タイプ  | 名前      | 値                 |
| ------- | --------- | ------------------ |
| `CNAME` | `roadmap` | 画面に表示される値 |

`acme.com` のような**ルートドメイン**には、代わりに `A` と `AAAA` を作成します。ルートドメインには `CNAME` を設定できません。メールやその他のサービスが依存する `MX` と `TXT` のレコードがすでに存在するためです。

| タイプ | 名前 | 値                 |
| ------ | ---- | ------------------ |
| `A`    | `@`  | 画面に表示される値 |
| `AAAA` | `@`  | 画面に表示される値 |

値は、必ず画面からコピーしてください。ほかの場所からコピーしてはいけません。これらは Motir が配信されるアドレスで、運用しているプラットフォームから取得しており、変更されることがあります。画面は変更に追従しますが、このようなページは追従しません。

> DNS プロバイダーがレコードに「プロキシ」や「クラウド」の切り替えを提供している場合は、オフにしてください。レコードの前段にプロキシがあると、確認の際にドメインが見えなくなり、証明書を発行できません。

### 2 · ドメインの所有を証明する {#prove-the-domain-is-yours}

ドメインを向けるレコードに加えて、画面にはトークンを含む `TXT` レコードが 1 つ表示されます。形は次のとおりです。

| タイプ | 名前                    | 値               |
| ------ | ----------------------- | ---------------- |
| `TXT`  | `_motir-verify.roadmap` | `motir-verify=…` |

値はここからではなく、画面からコピーしてください。トークンはお客様専用のものです。続いて _確認_ を選びます。レコードが確認できると証明書がリクエストされ、通常は 1〜2 分で完了します。ページを閉じても構いません。ステータスは自動的に更新され、レコードは _DNS レコードを表示_ からいつでも確認できます。

## どのアドレスが正式か {#which-address-is-the-real-one}

プロジェクトは複数のアドレスで表示できますが、そのうち _メイン_ になるのは 1 つだけです。検索エンジンやソーシャルメディアに伝えられるのはこのアドレスです。接続したドメインの証明書が公開中になると、そのドメインをメインにできます。それまでは Motir のアドレスがメインです。

**メイン以外のアドレスはすべて、メインにリダイレクトされます。** 独自ドメインをメインにした後は、`motir.co` のアドレスも同様です。訪問者は常に正常に表示される場所に到着し、検索エンジンは同じページの 3 つのコピーが競合する状態ではなく、1 つのページを認識します。

## ドメインの削除 {#removing-a-domain}

接続したドメインを削除すると、その証明書が取り消され、そのアドレスは応答しなくなります。そのアドレスを使っている人にはエラーが表示され、すでに共有されたリンクも機能しなくなります。プロジェクトはほかのアドレスで公開されたままなので、ドメインを削除してもプロジェクトが非公開になることはありません。

## うまく動作しないとき {#if-something-is-not-working}

失敗のほとんどは 3 つの間違いのどれかで、それぞれ画面での現れ方が異なります。

- **ルートドメインへの CNAME。** 多くのレジストラは設定を受け付けますが、動作しません。症状は、ドメインのステータスが「未確認」（`Not verified`）のままになるか、「失敗」（`Failed`）になることです。代わりに上記の `A` と `AAAA` のレコードを使ってください。
- **レコードの前段にあるプロキシ型の DNS プロバイダー。** プロバイダーがトラフィックのプロキシや高速化を提供している場合、実際のレコードが Motir から見えなくなります。症状は、「確認中…」（`Checking…`）がいつまでも終わらないことです。これらのレコードについてはプロキシをオフにしてください。
- **古い所有権レコード。** ドメインをいったん削除して再び追加した場合、トークンが変わっています。症状は、「未確認」（`Not verified`）のままなのに、`TXT` レコードが確かに存在することです。その値を、画面に現在表示されているものに置き換えてください。
