公开项目可以通过你选定的地址访问。每个工作区都可以认领一个属于自己的地址，项目还可以另外使用你已拥有的域名来提供服务。

## 你的 Motir 地址 {#your-motir-address}

一个工作区认领一个子域名，其下所有公开项目都在该子域名下提供服务——例如 `acme` 会给出 `acme.motir.site/ROADMAP`，对应的项目键为 `ROADMAP`。工作区的所有者或管理员可以在项目设置的 _公开地址_ 中认领它。

标签由小写字母、数字和连字符组成，长度为三到六十三个字符。有一小部分名称被保留，用于 Motir 自己的主机，以及读者可能误认为是 Motir 主机的名称。

可以重命名它，但次数有限，面板会显示还剩几次重命名机会。**旧地址之后仍然有效，而且永远不会被释放。** 它会永久重定向到新地址，也不能被任何其他人认领——包括日后的你自己。这是有意为之：别人已经分享出去的链接，不应在某一天通向你没有选择的地方。

## 连接你自己的域名 {#connecting-your-own-domain}

连接自己拥有的域名适用于付费方案——见[我们的方案](/)。工作区子域名在每个方案中都包含，无论是否连接域名都会继续有效。

一个已连接的域名只对应 _一个_ 项目，并位于其根路径：`roadmap.acme.com/` 是该项目的页面，`roadmap.acme.com/changelog` 是它的更新日志。实时面板、工作项和路线图都在 Motir 应用中，应用里的相关链接会指向那里。

你需要在域名注册商处创建两类记录。**请先添加域名**，在项目设置的 _公开地址_ 中操作：面板随后会列出该域名所需的每一条记录，附带准确的值，每条记录旁都有复制按钮。下面的形式只是让你预先了解——用它们确认你的注册商能创建这些记录，具体的值请以面板为准。

### 1 · 把域名指向我们 {#point-the-domain-at-us}

对于 **子域名**，例如 `roadmap.acme.com`，使用一条 `CNAME`：

| 类型    | 名称      | 值               |
| ------- | --------- | ---------------- |
| `CNAME` | `roadmap` | 以面板中显示为准 |

对于 **根域名**，例如 `acme.com`，则改用一条 `A` 和一条 `AAAA`——根域名不能使用 `CNAME`，因为它已经带有邮件和其他服务所依赖的 `MX` 与 `TXT` 记录：

| 类型   | 名称 | 值               |
| ------ | ---- | ---------------- |
| `A`    | `@`  | 以面板中显示为准 |
| `AAAA` | `@`  | 以面板中显示为准 |

请从面板而不是其他任何地方复制每个值。这些是 Motir 提供服务所用的地址，读取自我们所运行的平台，并且可能发生变化——面板会随之更新，而像本页这样的页面不会。

> 如果你的 DNS 服务商在记录上提供了“代理”或“云”开关，请把它关闭：记录前面的代理会使检查看不到你的域名，证书也就无法签发。

### 2 · 证明域名归你所有 {#prove-the-domain-is-yours}

除了指向记录之外，面板还会列出一条包含令牌的 `TXT` 记录，形式如下：

| 类型  | 名称                    | 值               |
| ----- | ----------------------- | ---------------- |
| `TXT` | `_motir-verify.roadmap` | `motir-verify=…` |

请从面板而不是这里复制该值——这个令牌只属于你。然后选择 _验证_。一旦我们能看到这条记录，就会申请证书，通常一两分钟内完成。你可以关闭页面；状态会自行继续推进，记录仍可在 _查看 DNS 记录_ 下找到。

## 哪个地址才是正式地址 {#which-address-is-the-real-one}

一个项目可以在多个地址上提供服务，其中恰有一个是 _主地址_——搜索引擎和社交平台的链接预览得到的就是它。已连接域名的证书生效后，你可以把它设为主地址；在此之前，主地址是 Motir 地址。

**其他所有地址都会重定向到主地址。** 这也包括你的 `motir.co` 地址，只要你已把自己的域名提升为主地址。访问者总会到达一个可用的地方，搜索引擎看到的也是一个页面，而不是三份相互竞争的副本。

## 移除域名 {#removing-a-domain}

移除一个已连接的域名会撤回它的证书，该地址也不再响应——使用它的人会遇到错误，之前分享到该地址的链接也会失效。你的项目在其他地址上仍然保持公开，因此移除域名绝不会让项目变为私有。

## 如果某处不能正常工作 {#if-something-is-not-working}

几乎所有故障都源于三种错误，每一种在面板中的表现各不相同。

- **在根域名上使用 CNAME。** 大多数注册商都接受，但它并不起作用。表现是域名一直停留在 `Not verified`，或者进入 `Failed`。请改用上面的 `A` 和 `AAAA` 记录。
- **记录前面有代理型 DNS 服务商。** 如果你的服务商提供代理或加速流量的功能，就会向我们隐藏真实的记录。表现是 `Checking…` 始终无法结束。请对这些记录关闭代理。
- **过时的所有权记录。** 如果你移除后又重新添加了域名，令牌就变了。表现是状态为 `Not verified`，而一条 `TXT` 记录明明就在那里。请把它的值替换为面板现在显示的值。
