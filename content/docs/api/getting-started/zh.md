公开读取 API 是匿名的——每个读取端点无需登录就会返回项目数据，这正是项目广场能为未登录访客工作的原因。所有与账户绑定的内容都需要携带令牌。下面分五步，每一步都以你能亲眼看到的结果收尾。

每个路径都相对于此构建所指向的应用主机，如下所示。请求都是针对它写的，所以你可以原样复制。

{{slot:app-host}}

## 1. 生成令牌 {#mint-a-token}

在“设置”→“账户”→“令牌”中生成一个个人访问令牌，选择它所绑定的工作区，并授予它所需的权限——与“角色与权限”界面显示的是同样的 `resource:action` 名称。请授予能完成任务的最窄集合：授权只会收窄你自己的角色而不会放宽，所以令牌不能做你本人做不到的事。

**密钥只在创建令牌时显示一次。** 请当时就复制；之后无法再次读取，丢失的令牌只能替换，无法找回。

## 2. 你的第一次认证调用 {#first-call}

请先发出这个调用。它会回答令牌是谁、绑定到哪个工作区，以及它究竟带有哪些权限——这样你无需逐个端点试探、收集一堆拒绝，就能知道自己的凭据可以做什么。

{{slot:first-call-request}}

{{slot:first-call-response}}

令牌缺失、格式错误、未知、已撤销或已过期，都会返回同样的 `401` 和同样的消息。这是有意为之：如果区分它们，端点就会变成一个能回答“这个密钥是否存在？”的探测器。

## 3. 对集合分页 {#paginate}

集合采用游标分页。用 `limit` 指定页大小（默认是 50，超过 100 的值会被限制为 100，而不是被拒绝），然后把上一次响应中的 `nextCursor` 作为 `cursor` 发回。`nextCursor` 为 `null` 表示这是最后一页。

{{slot:paginate-first-request}}

{{slot:paginate-first-response}}

{{slot:paginate-next-request}}

游标是不透明且经过签名的。不要解析它、自行构造，也不要在不同集合之间沿用——在别处签发的游标会得到 `422`，而绝不会悄悄返回一个错误的页面。请原样发回你拿到的内容。

有一处不对称常让人意外，值得在遇到之前先知道：有些集合还会报告 `totalCount`，而大多数有意不报告。当某个集合背后的读取本来就以有界聚合的方式算出了总数时，才会报告它；否则这个字段会被整个省略——是缺失，绝不是 `null`，也绝不是 `0`，因此客户端总能区分“没有承诺提供总数”和“总数为零”。

## 4. 读懂错误 {#read-an-error}

每次失败都返回相同的响应体：机器可读的 `code` 和面向人的 `error`。请根据 `code` 分支处理——它是稳定的，更改它属于破坏性变更。绝不要解析 `error`；它是写给在终端前阅读的开发者的一句话，可以随意改写。

{{slot:error-404-response}}

`404` 表示资源不存在 **或者** 位于你的令牌所绑定的工作区之外——这是有意给出同样的回答，这样就无法利用 API 去枚举其他租户的数据。`403` 则是相反的一类拒绝：你的令牌有效，但它的授权缺少这个操作所需的权限，响应中会指明该权限的键。`422` 是你可以修正的请求，它的 `code` 会指出是哪个部分。

**`500` 是唯一没有 `code` 的失败。** 意外故障没有稳定的契约，所以响应体只带一条消息，别无其他——不要据此分支处理。

## 5. 读取响应头 {#rate-limits}

额度是按令牌计算的，而且这些响应头会出现在每一个响应中——无论是成功、拒绝、已映射的错误还是故障。你无需专门发出请求来查看自己的处境；上一个请求已经告诉了你。

{{slot:response-headers}}

遇到 `429` 时，请退避到 `X-RateLimit-Reset`——这是以秒为单位的 Unix 时间戳。这里有意没有 `Retry-After` 响应头：绝对时刻不会像相对时长那样在传输途中过时。

`X-Request-Id` 也在每个响应中。如果你需要就某个具体调用向我们咨询，请引用它——它是能找到该调用的唯一标识。

`X-Motir-Api-Version` 是服务该响应的契约版本——采用 `MAJOR.MINOR.PATCH` 格式，与规范中的 `info.version` 相同，而不是我们的发布版本号。可以从任何响应（包括失败的响应）中读取它，以检查版本偏差。如果出现你不认识的 MAJOR，说明已有 `/api/v2`；更高的 MINOR 则表示契约以增量方式扩展了，你的客户端依然正确。如果上面的区块显示的是占位符而不是版本号，说明渲染本页时规范无法访问，此时 [API 参考](/docs/api)会直接从文档中读取当前版本。
